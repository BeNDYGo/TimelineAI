# TimelineAI

Python-пайплайн для автоматического создания и публикации коротких вертикальных роликов. Из идеи он генерирует историю, раскадровку, изображения, озвучку, субтитры и итоговый MP4, затем публикует его как Instagram Reel.

## Поток данных

```text
идея + core.md
    ↓
агент 1: текст озвучки
    ↓
агент 2: раскадровка и промпты изображений
    ↓
агент 3: MCP-инструменты
    ↓
PNG + MP3 → manifest → FFmpeg → MP4 → Upload-Post
```

`pipeline.py` — единая точка запуска. Он читает `core.md`, запрашивает идею и последовательно запускает три агента.

## Ядро канала

`core.md` — меняемая конфигурация конкретного канала: тематика, речь, формат, визуальный стиль, постоянные персонажи и запреты.

- Агент 1 получает `core.md`, чтобы сюжет и манера речи соответствовали каналу.
- Агент 2 получает `core.md`, чтобы образы, кадры и промпты картинок соответствовали каналу.
- Агент 3 не получает `core.md`: он не придумывает контент, а исполняет готовую раскадровку.

Творческие требования `core.md` имеют приоритет над общими примерами в системных промптах.

## Ключевые файлы

- `pipeline.py` — точка входа и оркестрация.
- `core.md` — стиль и правила канала.
- `BaseAI/prompts.py` — системные промпты трёх агентов.
- `BaseAI/agent1_producer.py` — генерация текста озвучки.
- `BaseAI/agent2_screenwriter.py` — генерация раскадровки.
- `BaseAI/agent3_director.py` — MCP-клиент и оркестратор производства.
- `timeline_mcp/server.py` — инструменты генерации, manifest, сборки и публикации.
- `TTI/TTI.py` — генерация PNG 9:16.
- `TTS/TTS.py` — синтез MP3 и определение длительности через `ffprobe`.
- `video/manifest.json` — временный список сцен текущего ролика.
- `video/assembler.py` — Ken Burns, склейка и сборка MP4 через FFmpeg.
- `video/subtitles.py` — пословные субтитры через Pillow.
- `config.py` — пути, RouterAI URL и загрузка `.env`.
- `VODS/` — сгенерированные PNG и MP3.
- `final_*.mp4` — итоговые ролики в корне.

`Blok/blok.py`, `TTS/API-TTS.py` и `test_TTI.py` не участвуют в основном потоке.

## Модели и сервисы

- Агенты: `deepseek/deepseek-v4-flash` через RouterAI.
- Изображения: `recraft/recraft-v4.1-utility` через RouterAI.
- Озвучка: `x-ai/grok-voice-tts-1.0`, голос `leo`, через RouterAI.
- Публикация: Upload-Post API, Instagram Reels.

Вызовы RouterAI и Upload-Post могут быть платными. Не запускать `pipeline.py`, `TTI/TTI.py`, `TTS/TTS.py` или реальную публикацию для обычной проверки.

## Конфигурация

`.env` в корне:

```dotenv
ROUTERAI_API_KEY=...
UPLOAD_POST_API_KEY=...
UPLOAD_POST_USER=...
```

`ROUTERAI_API_KEY` обязателен уже при импорте `config.py`. Параметры Upload-Post нужны только для публикации.

## Запуск

Требуются Python, зависимости из `requirements.txt`, FFmpeg и `ffprobe`.

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python pipeline.py
```

Полный запуск сразу генерирует платный контент и после сборки пытается его опубликовать.

## Безопасные проверки

```bash
python3 -m py_compile pipeline.py BaseAI/*.py timeline_mcp/*.py TTI/*.py TTS/TTS.py video/*.py
python3 -m unittest test_publish_video.py
```

Тест публикации мокает HTTP-запрос и не публикует реальный ролик.

## Важные инварианты

- Порядок MCP-вызовов: очистка manifest → картинка → озвучка → сцена → сборка → однократная публикация.
- После ошибки платный вызов не повторяется.
- Номера сцен идут с 1 без пропусков.
- Текст сцены передаётся в manifest без изменений для пословных субтитров.
- Промпты картинок одного ролика сохраняют общий стиль и одинаковые описания постоянных персонажей.
