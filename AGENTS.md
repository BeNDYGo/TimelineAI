## Контекст проекта

TimelineAI — Python-пайплайн, который из идеи создаёт и публикует короткий вертикальный ролик:

```text
идея + core.md
  -> агент 1: текст озвучки
  -> агент 2: раскадровка, изображения и движения камеры
  -> агент 3: вызовы MCP-инструментов
  -> PNG + MP3 + manifest
  -> FFmpeg: сцены, субтитры и итоговый MP4
  -> Upload-Post: Instagram Reel
```

`pipeline.py` — единственная основная точка запуска. Он читает `core.md`, получает идею пользователя и последовательно запускает трёх агентов.

`core.md` — изменяемая конфигурация канала: тематика, речь, длительность, визуальный стиль, персонажи и запреты. Его требования имеют приоритет над общими примерами промптов.

## Карта кода

- `BaseAI/agent1_producer.py` — создаёт цельный текст озвучки.
- `BaseAI/agent2_screenwriter.py` — превращает текст в раскадровку.
- `BaseAI/agent3_director.py` — исполняет раскадровку через MCP; контент не придумывает.
- `BaseAI/prompts.py` — системные промпты всех трёх агентов.
- `timeline_mcp/server.py` — MCP-инструменты генерации, manifest, сборки и публикации.
- `TTI/TTI.py` — платная генерация вертикальных PNG через RouterAI.
- `TTS/TTS.py` — платный синтез MP3 и определение длительности через `ffprobe`.
- `video/manifest.json` — временные данные сцен текущего ролика.
- `video/assembler.py` — движения камеры/Ken Burns, FFmpeg-сборка и склейка.
- `video/subtitles.py` — пословные субтитры через Pillow.
- `config.py` — пути, переменные окружения и адрес RouterAI.
- `PROJECT.md` — пользовательская документация проекта; читать только если для задачи недостаточно этого файла.

`Blok/blok.py`, `TTS/API-TTS.py` и `test_TTI.py` не входят в основной поток.

## Важные инварианты

- Производственный порядок: `clear_manifest` -> для каждой сцены `generate_image` -> `generate_speech` -> `add_scene` -> `assemble_video` -> один вызов `publish_video`.
- После ошибки платный вызов не повторяется.
- Номера сцен начинаются с 1 и идут без пропусков.
- Текст сцены попадает в manifest без изменений: он нужен для синхронизации субтитров.
- Общий визуальный стиль и описание повторяющихся персонажей должны быть одинаковыми во всех промптах изображений ролика.
- Параметры камеры проходят из раскадровки через `add_scene` и manifest в `video/assembler.py`: `motion`, `zoom_start`, `zoom_end`, `pan_x`, `pan_y`.
- Zoom-out без пустых полей начинается с масштаба больше `1.0` и заканчивается на `1.0`; масштаб меньше `1.0` требует отдельного решения для фона или полей.

## Проверка без расходов

Не запускать `pipeline.py`, генерацию TTI/TTS и реальную публикацию: они могут вызвать платные внешние API.

Разрешённые базовые проверки:

```bash
python3 -m py_compile pipeline.py BaseAI/*.py timeline_mcp/*.py TTI/*.py TTS/TTS.py video/*.py
python3 -m unittest test_publish_video.py
```

Тест публикации мокает HTTP-запрос и ничего не публикует. Для новой нетривиальной логики добавляй минимальный локальный тест без сети.
