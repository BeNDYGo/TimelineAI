# TimelineAI

Python-пайплайн, который из одной идеи создаёт короткий вертикальный ролик: пишет историю, делает раскадровку, генерирует изображения и озвучку, добавляет движения камеры и пословные субтитры, собирает MP4 и публикует его как Instagram Reel.

## Контекст для ИИ в новом чате

Сначала прочитай [`AGENTS.md`](AGENTS.md). Это основной и актуальный контекст проекта: правила работы, архитектура, карта файлов, инварианты и безопасные проверки.

Не обозревай весь репозиторий заново. После `AGENTS.md` открывай только файлы, непосредственно относящиеся к текущей задаче. Если документация расходится с кодом, источником истины является код; после изменения обнови затронутую документацию.

## Как работает проект

```text
идея + core.md
  -> агент 1: текст озвучки
  -> агент 2: раскадровка, изображения и движения камеры
  -> агент 3: вызовы MCP-инструментов
  -> PNG + MP3 + manifest
  -> FFmpeg: сцены, субтитры и итоговый MP4
  -> Upload-Post: Instagram Reel
```

`pipeline.py` — основная точка запуска. `core.md` задаёт тематику, речь, длительность, визуальный стиль, персонажей и запреты канала; его требования имеют приоритет над общими примерами промптов.

## Основные файлы

- `BaseAI/prompts.py` — системные промпты трёх агентов.
- `BaseAI/agent1_producer.py` — генерация текста озвучки.
- `BaseAI/agent2_screenwriter.py` — создание раскадровки.
- `BaseAI/agent3_director.py` — исполнение раскадровки через MCP.
- `timeline_mcp/server.py` — инструменты генерации, manifest, сборки и публикации.
- `TTI/TTI.py` — генерация изображений.
- `TTS/TTS.py` — синтез речи.
- `video/manifest.json` — временные данные сцен текущего ролика.
- `video/assembler.py` — движения камеры и FFmpeg-сборка.
- `video/subtitles.py` — пословные субтитры.
- `PROJECT.md` — расширенная пользовательская документация.

## Важно

Генерация изображений, озвучка и публикация используют внешние API и могут быть платными. Для обычной проверки не запускай `pipeline.py`, TTI/TTS или реальную публикацию.

Безопасные локальные проверки:

```bash
python3 -m py_compile pipeline.py BaseAI/*.py timeline_mcp/*.py TTI/*.py TTS/TTS.py video/*.py
python3 -m unittest test_publish_video.py
```
